# ざっくりしたイメージから案を出してもらう

- Aura を使って、宇宙を感じるパターンを５つ考えてください。
    1. 星のまたたき(ランダムスター) : 
    ランダムなLEDだけを白(WHITE)で短く光らせ、他はOFF。random.randint(0,5) で毎回光る位置を変える。
    2. 星雲(ネビュラ)グラデーション : 
    紫・青・ピンクなど宇宙っぽい色を隣同士で少しずつ混ぜてグラデーションにし、全体をゆっくり左右にシフトさせる(既存コードの cnt によるずらしと同じ仕組み)。
    3. 流れ星 : 
    1〜2個の白いLEDが端から端へ一定方向に流れ、通過後は青紫の残光(GLOW)で少しずつ暗くなってから消える。
    4. オーロラの波 : 
    緑〜青〜紫を正弦波(math.sin)で明るさ変調しながら、位相をLEDごとにずらして波打つように光らせる。
    5. 惑星の鼓動(深宇宙パルス) : 
    LED全体を濃い青や紫で同時にゆっくり明滅させる(time.sleep を使ったフェードイン・フェードアウト)。心拍のような静かな呼吸感を演出。

- Aura を使って、空の変化を表すようなパターンを５つ考えてください。
    1. 夜明け(暁) : 
    濃紺(NIGHT)からオレンジ〜ピンクへ、全LED同時にゆっくり色をクロスフェードさせる。
    2. 青空 : 
    全LEDを爽やかな水色(BLUE寄りの薄い青)で安定点灯。時々WHITEを一瞬混ぜて雲の通過を表現。
    3. 夕焼け : 
    端から順にオレンジ→赤紫へとcntでグラデーションを流し、徐々に暗くなるRED/WHITE配合で夕暮れ感を出す。
    4. 満天の星(夜空) : 
    ベースを暗い紺(WHITE弱め+わずかなBLUE)にし、ランダムなLEDだけ一瞬WHITEで瞬かせる。
    5. 雷雨 : 
    通常は暗いグレー(WHITE弱)で沈めておき、不規則なタイミングで全LEDを一瞬強いWHITEでフラッシュさせて雷を表現。

- Aura を使って、夜に身体に付けていると目立つような刺激的なパターンを５つ考えてください
    1. レインボーチェイス : 
        虹色(RED→GREEN→BLUE→WHITE...)を高速でcnt回転させ、LED間の色差を大きくして視認性を上げる。
    2. ストロボフラッシュ : 
        全LEDを白(WHITE)で0.1秒未満の短い間隔でON/OFFを繰り返す、強めの点滅。
    3. ポリスライト : 
        RED側3個とBLUE側3個に分け、左右交互に高速点滅させる緊急車両風パターン。
    4. コメットスパーク : 
        1個だけ明るいWHITEが高速で一周し、その後ろに短い残光(RED/BLUE混色)を尾のように残す。
    5. カラーパルス : 
        全LED同時に、RED→GREEN→BLUE→WHITEの順で1色ずつパッと切り替える、心拍のような強い明滅。
